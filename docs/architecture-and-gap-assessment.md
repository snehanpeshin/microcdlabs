# Current architecture and capabilities
Reviewed November 6, 2026.

The maintained site is static HTML, CSS and JavaScript, hosted by AWS Amplify without a server build. No supported inquiry-delivery endpoint, database, secret store, or maintained PDF backend is present. Email preparation is not submission.

The 2D Modeler and Kinetic Assay Analyzer are maintained ES modules with Node tests. The original compiled 3D Modeler remains a separate GLB workspace at /modeler/core.html. /modeler/app/ redirects to the maintained browser entry; it is not proof of native iOS capability. Current native iOS sources are not part of this checkout.

Names, versions, formats, requirements, and data boundaries come from assets/tool-definitions.js. Run node tools/sync-tool-content.mjs after changing supported capabilities. STEP/DXF remain disabled, not newly implemented.

The 2D Modeler uses localStorage autosave and a scoped service-worker asset cache. The Analyzer uses in-memory CSV/image data and local downloads/printing. CRP Camera separately supports local IndexedDB records and image storage. No analytical formulas changed in this upgrade.

The quotation basket uses versioned sessionStorage records; only SKU-linked item selection/configuration, quantities, and technical notes are retained. Prices and configuration require written review. The historical generic Stripe URL is not a quote-bound approved payment flow and is not used by the basket.

Shared marketing headers and footers are generated by node tools/sync-marketing.mjs. Scientific workspaces keep their specialized chrome. Chat loads on explicit request, not automatically.

Before true inquiry delivery, configure an approved server-side endpoint, destination, credentials, validation/rate limits, origin rules, and delivery monitoring. Never put credentials in this static site.

Owner review remains needed for legal-entity relationship wording, consent/provider settings, current iOS capabilities, publishable physical prototypes/CAD, final CLAIR reader/mobile architecture, and any analytical/clinical evidence. No team biography has been added.
