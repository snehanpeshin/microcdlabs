# Changelog

## 2.0.0-beta.1 — 2026-08-17

- Added a shared MicroCD Labs scientific design system with responsive, keyboard-visible states.
- Rebuilt the hosted Modeler as a professional 2D workspace with versioned projects, recovery, history, parametric features, layers, advisory DRC, engineering estimates, and real JSON/SVG/PNG/CSV exports.
- Preserved the compiled legacy 3D workspace and GLB workflow as an explicitly separate preview.
- Renamed the hosted product to Kinetic Assay Analyzer and retained old route entry points.
- Added a five-stage, local-first Analyzer with validated CSV/image import, visual ROIs, deterministic preprocessing, pure metrics, QC, manifest checksums, reproducible exports, and printable reports.
- Removed product advertising from the new hosted applications and from the native Modeler controller configuration.
- Added architecture, methodology, and user quick-start documentation plus dependency-free tests.
