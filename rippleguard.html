What the user gets

A privacy monitor for spaces where cameras feel wrong.

Room State

Shows whether the room looks quiet, disturbed, or changed compared with its recent baseline.

Protected Zone

Lets a user calibrate areas such as a doorway, desk, cabinet, bed, or window and watch likely disturbance zones.

Local Dashboard

Streams to a browser app on the local network with live charts, event cards, and CSV export.

Cheap First Build

Designed around one ESP32 Wi-Fi/BLE SoC, USB power, a status LED, and a calibration button.

How it works

RippleGuard compares live wireless patterns to a calm-room baseline.

  1. 01

    Place

    Put RippleNode One near a router, doorway, cabinet, desk, or protected path.

  2. 02

    Baseline

    Keep the room still while RippleGuard learns the normal signal pattern.

  3. 03

    Calibrate

    Stand in each important zone once so the app can learn rough fingerprints.

  4. 04

    Monitor

    Review movement likelihood, confidence, likely zone, and event history.

Prototype boundary

Room privacy signal estimate, not imaging.

RippleGuard does not image people, identify people, or scan inside the body. It estimates room-level wireless disturbance patterns for experimentation and privacy monitoring trials.

The manufacturable target is a compact plug-in room node that works near an existing Wi-Fi router to keep total system cost low.
